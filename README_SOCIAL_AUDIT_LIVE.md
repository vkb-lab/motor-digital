# Checkpoint 30B - Social Audit Live Mode

Objetivo:
mostrar na Lousa/Social Audit o andamento da auditoria visual.

Fluxo:
auditoria enviada
-> fila local
-> aprovacao humana
-> Runner executa
-> navegador visual abre
-> status live e atualizado
-> screenshots por etapa
-> relatorio final

Regras:
- somente leitura
- sem publicacao
- sem DM
- sem login forcado
- sem operacao oficial de conta
