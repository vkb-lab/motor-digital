# K-OS Fase 15 Creative Asset Publisher

Objetivo:
Criar uma arte PNG real para campanha e preparar uma URL publica HTTPS para o Instagram.

Fluxo:
- Gerar PNG local em public/kos/assets/
- Criar manifest JSON da arte
- Detectar URL publica via KOS_PUBLIC_BASE_URL ou deploy Vercel
- Entregar image_url_for_instagram para o publicador real

Esta fase nao publica no Instagram.
