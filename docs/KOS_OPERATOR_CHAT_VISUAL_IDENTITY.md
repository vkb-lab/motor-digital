# K-OS Operator Chat Visual Identity

## Proposito auditado

K-OS e a camada operacional local do Motor Digital/K-Atlas: um OS de agentes, memoria, campanhas, SaaS factory, conexoes e execucao supervisionada. A interface principal deve reduzir carga cognitiva e fazer o operador sentir que esta conversando com um coworker operacional, nao preenchendo um formulario tecnico.

## Principios visuais

- Chat-first: o pedido em linguagem natural e o centro da tela.
- Operacional, nao marketing: visual calmo, denso o suficiente, sem hero promocional.
- Evidencia sem susto: logs, paths e registries aparecem como prova, nao como alerta.
- Autonomia supervisionada: status de Human Gate sempre claro, sem bloquear a conversa.
- Baixa carga cognitiva: poucos blocos, hierarquia curta e proximos pedidos naturais.

## Identidade

- Base: branco operacional e cinza frio claro.
- Texto: ink escuro para leitura longa.
- Acentos: azul para inteligencia/rota, verde para seguranca/execucao aprovada.
- Alerta: amarelo/laranja apenas para limite de seguranca, sem vermelho como estado normal.
- Forma: raio de 8px, linhas finas, sem cards decorativos empilhados.

## Linguagem

Usar termos como:
- "O que posso acionar agora"
- "Pronto para revisao"
- "Limite de seguranca"
- "Evidencia local"
- "Responda por texto"

Evitar como resposta principal:
- nomes tecnicos de modulos sem traducao operacional
- banners de dashboard
- instrucoes de PowerShell no fluxo comum
- botao como unico contrato mental
