# K-OS Engineer Packet One-Click Runner v0.69K

Objetivo:
Reduzir copia-e-cola e juntar 69I + 69J em um unico comando.

Fluxo:
- le pacote do clipboard ou arquivo
- roda intake 69I
- se seguro, promove com 69J
- opcionalmente roda tick do handoff queue
- nao executa comando final automaticamente

Atalho:
KOS_Engineer_Packet_OneClick.cmd

Comando:
powershell -ExecutionPolicy Bypass -File scripts\run_kos_engineer_packet_oneclick.ps1 -FromClipboard

Arquivo:
powershell -ExecutionPolicy Bypass -File scripts\run_kos_engineer_packet_oneclick.ps1 -File local_runtime\kos_engineer_command_intake\samples\sample_69k_packet.txt
