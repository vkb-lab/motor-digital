# K-OS Operator Chat Frontdoor v0.72D

Objetivo:
Transformar o K-OS em uma porta unica de uso por linguagem natural.

Uso:
C:\\Users\\oi\\Desktop\\KOS_START_HERE.cmd

O operador escreve o pedido em linguagem normal.
O K-OS classifica, consulta contexto, escolhe rota e mostra o proximo passo.

Decisao UX:
- detalhes tecnicos ficam escondidos
- cockpit tecnico continua existindo
- usuario usa apenas a caixa de pedido

Garantias:
- nao cria publicador novo
- nao cria orquestrador paralelo
- nao publica automaticamente
- nao aplica patch automaticamente
- nao usa IA paga
- nao faz scraping
- Parada Atlantida bloqueada
