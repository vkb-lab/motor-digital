# Perguntas para Mentor de Startup

## Produto

1. Qual deve ser o primeiro ICP do K-OS?
2. Devemos vender para pequenos negócios, agências ou founders?
3. O produto inicial deve ser cockpit, agência aumentada ou SaaS vertical?
4. Como simplificar a proposta para pitch de 30 segundos?

## Mercado

1. Qual dor é mais urgente: marketing, automação, atendimento ou criação de produto?
2. Quem pagaria primeiro?
3. Qual vertical é mais fácil para tração inicial?
4. Qual caso-escola vira demo comercial?

## Tecnologia

1. Qual stack cloud priorizar?
2. Quando migrar JSON para banco?
3. Como desenhar multi-tenant com segurança?
4. Como separar agentes, permissões e billing?

## Go-to-market

1. Começar como serviço operacional ou produto self-service?
2. Criar planos por uso, por agente ou por negócio?
3. Qual métrica prova valor em 7 dias?
4. Como demonstrar ROI rapidamente?

## Risco

1. O escopo está amplo demais?
2. Qual funcionalidade cortar primeiro?
3. Qual integração pode gerar risco jurídico?
4. Como evitar virar apenas mais uma interface de IA?
