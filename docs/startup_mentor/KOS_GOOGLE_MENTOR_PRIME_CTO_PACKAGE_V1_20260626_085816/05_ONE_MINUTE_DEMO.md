# O que o usuário consegue fazer em 1 minuto

## Cenário 1 — Operar o cockpit

1. Abrir KOS_START_HERE.cmd.
2. Entrar no Operator Chat.
3. Digitar um pedido.
4. Receber rota, ação segura e próximo passo.

## Cenário 2 — Melhorar uma campanha

Pedido:

melhorar GP_VIDEO_02 usando referencia Manus score briefing prompts

Resultado:

- rota identificada;
- script local executado;
- score criado;
- briefing criado;
- prompt pack criado;
- preview local exibido;
- publicação bloqueada.
