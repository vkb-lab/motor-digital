# K-OS User-Friendly Local Launcher v0.69B

## Objetivo

Permitir que um usuario use o K-OS em 5 minutos sem decorar PowerShell.

## Como abrir

Clique em:

KOS_User_Launcher.cmd

Ou rode:

powershell -ExecutionPolicy Bypass -File scripts\start_kos_user_launcher.ps1

## Launcher web

powershell -ExecutionPolicy Bypass -File scripts\start_kos_user_launcher.ps1 -Mode user-dashboard

## Regras

- Nao publica Instagram.
- Nao chama IA paga.
- Nao usa navegador logado.
- Kill Switch exige acao humana.
