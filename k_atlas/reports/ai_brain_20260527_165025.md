## Pedido
use IA para criar um plano curto de evolução do K-Work com Supabase, worker local e cockpit multiaparelhos

## Resposta
Com certeza. O plano focará em modularidade, baixo custo e escalabilidade rápida.

---

### Diagnóstico

O K-Work atual precisa de uma evolução para se tornar mais autônomo, reativo e acessível. A integração de IA pode otimizar processos, enquanto o Supabase oferece uma base de dados e autenticação robusta e de baixo custo. O "worker local" garante processamento específico e seguro, e o "cockpit multiaparelhos" universaliza o acesso e a operação.

---

### Plano

**Objetivo:** Modernizar K-Work com IA, Supabase, worker local e um cockpit universal, focando em MVP e evolução incremental.

**Fases:**

1.  **Infraestrutura Core (Supabase & Base de Dados):**
    *   Configurar projeto Supabase (Database, Auth, Storage).
    *   Definir esquema de dados inicial para K-Work (tarefas, usuários, resultados, status).
    *   Implementar autenticação de usuários via Supabase Auth.
    *   Criar Edge Functions básicas para API de comunicação (ex: criação de tarefa, atualização de status).

2.  **Worker Local & Conectividade:**
    *   Desenvolver um script worker simples (Python/Node.js) para rodar localmente.
    *   Configurar o worker para "escutar" novas tarefas do Supabase (via Realtime ou polling de Edge Function).
    *   Implementar a lógica de execução da tarefa no worker.
    *   Configurar o worker para reportar o status e resultados de volta ao Supabase.

3.  **Cockpit Multi-Aparelhos (Frontend):**
    *   Escolher um framework de frontend (ex: Next.js, SvelteKit) para web, otimizado para Progressive Web App (PWA).
    *   Desenvolver a interface básica para:
        *   Login/Logout.
        *   Visualizar tarefas e seus status.
        *   Criar novas tarefas.
        *   Visualizar resultados das tarefas.
    *   Conectar o frontend ao Supabase para dados e autenticação.
    *   Garantir responsividade para uso em diversos aparelhos (desktop, tablet, mobile).

4.  **Integração de IA (Funcionalidade Vertical):**
    *   Identificar um caso de uso específico para IA (ex: sumarização de resultados de workers, sugestão de próximas ações, categorização de tarefas).
    *   Integrar uma API de IA (ex: OpenAI GPT, Gemini) via Supabase Edge Function ou diretamente no worker local, dependendo da necessidade de processamento e dados.
    *   Exibir os insights/ações da IA no Cockpit.

---

### Execução (MVP - Mês 1)

**Foco:** Estabelecer a comunicação básica entre Cockpit, Supabase e Worker.

1.  **Supabase Setup (3 dias):**
    *   Criar projeto Supabase.
    *   Definir tabelas `tasks` (id, title, description, status, assigned_to, created_at, updated_at, result) e `users`.
    *   Configurar RLS (Row Level Security) básico para `tasks`.
    *   Criar uma Edge Function `create_task` e `update_task_status`.
2.  **Worker Local Prototyping (5 dias):**
    *   Desenvolver um script Python simples (`worker.py`).
    *   Configurar para fazer polling (a cada 30s) na Edge Function `get_pending_tasks` (a ser criada) ou usar Realtime do Supabase.
    *   Implementar uma "tarefa" dummy (ex: simular processamento por 5 segundos e gerar um resultado simples).
    *   Enviar o status e resultado da tarefa de volta via Edge Function `update_task_status`.
3.  **Cockpit Básico (7 dias):**
    *   Inicializar projeto Next.js/SvelteKit.
    *   Criar página de login/logout com Supabase Auth.
    *   Criar página "Minhas Tarefas" para listar tarefas do usuário, permitir criar nova tarefa e ver detalhes (status, resultado).
    *   Conectar com Supabase via SDK para buscar e criar tarefas.
