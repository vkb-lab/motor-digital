## K-Work Evolution: Supabase, Worker Local & Cockpit Multi-Aparelhos

### Diagnóstico

K-Work necessita de uma evolução para otimizar a automação de tarefas, garantir operações offline/locais e oferecer uma interface unificada e responsiva em múltiplos dispositivos. A integração com IA visa aprimorar a inteligência do fluxo de trabalho. A arquitetura atual pode estar limitada em escalabilidade ou flexibilidade.

### Plano

**Objetivo Geral:** Transformar K-Work em uma plataforma inteligente, robusta e acessível, com foco em simplicidade e execução rápida.

1.  **Fase 1: Fundação Supabase & Cockpit Básico (1-2 semanas)**
    *   **Infraestrutura:**
        *   Provisionar novo projeto Supabase (Database, Auth, Realtime, Storage).
        *   Definir schema inicial: `tasks`, `projects`, `users`, `worker_logs`.
    *   **Backend:**
        *   Utilizar Supabase PostgREST para API de CRUD (sem necessidade de backend customizado).
        *   Implementar autenticação de usuários via Supabase Auth.
    *   **Frontend (Cockpit MVP):**
        *   Desenvolver um Progressive Web App (PWA) inicial (ex: com Svelte/Vue/React) para login, visualização e criação de tarefas básicas.
        *   Garantir responsividade básica para desktop e mobile.

2.  **Fase 2: Worker Local & Sincronização (2-3 semanas)**
    *   **Módulo Worker:**
        *   Desenvolver um pequeno "K-Worker" (ex: Node.js ou Python) que possa ser executado localmente.
        *   Este Worker se autenticará com Supabase Auth e consumirá tarefas da tabela `tasks` (filtrando por `assigned_worker_id`).
        *   Implementar lógica para executar scripts/comandos locais baseados em `task_payload`.
    *   **Sincronização:**
        *   Utilizar Supabase Realtime para notificar o Worker sobre novas tarefas e para o Worker reportar o status (`pending`, `running`, `completed`, `failed`) e logs de volta para o Supabase.
        *   Desenvolver lógica de `offline-first` para o Worker (cache de tarefas, re-sync quando online).
    *   **Cockpit:**
        *   Atualizar Cockpit para exibir status em tempo real das tarefas executadas pelo Worker.
        *   Adicionar interface para atribuir tarefas a Workers específicos.

3.  **Fase 3: Inteligência Artificial (IA) & Cockpit Multi-Aparelhos (2-4 semanas)**
    *   **Integração IA (MVP):**
        *   Identificar um ponto de valor alto e de baixa complexidade (ex: Sugestão de tarefas baseado em contexto, Resumo de logs de worker, Priorização de tarefas).
        *   Integrar via API (ex: OpenAI GPT) para um caso de uso específico. Pode ser um `Supabase Edge Function` ou uma chamada direta do Cockpit.
    *   **Cockpit Multi-Aparelhos Avançado:**
        *   Refinar o PWA para uma experiência de usuário (UX) otimizada em smartphones, tablets e desktops.
        *   Implementar notificações push para PWA via Supabase (se aplicável, ou serviço externo).
        *   Adicionar dashboards de status e progresso.

### Execução (Primeira Etapa - MVP para K-Work V2)

1.  **Setup Supabase:** Criar novo projeto. Gerar chaves API.
2.  **Schema Database:**
    ```sql
    CREATE TABLE users (
      id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
      email TEXT UNIQUE,
      created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
    );

    CREATE TABLE tasks (
      id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
      title TEXT NOT NULL,
      description TEXT,
      status TEXT DEFAULT 'pending', -- pending, running, completed, failed
      priority INT DEFAULT 0,
      assigned_to UUID REFERENCES users(id),
      created_by UUID REFERENCES users(id),
      created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
      updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
      worker_id UUID, -- Referência futura ao worker
      payload JSONB -- Dados para o worker executar
    );

    -- RLS policies para garantir segurança.
    ```
3.  **Autenticação:** Habilitar email/senha no Supabase Auth.
4.  **Cockpit V1 (PWA):**
    *   Desenvolver uma aplicação web simples (ex: SvelteKit) com:
        *   Página de Login/Cadastro via Supabase Auth.
        *   Página "Minhas Tarefas" listando tarefas atribuídas ao usuário logado.
        *   Formulário para criar novas tarefas.
    *   Deploy para Vercel/Netlify (baixo custo e rápido).
