---

### **DIAGNÓSTICO**

O objetivo é criar uma plataforma de gerenciamento e automação de tarefas (K-Work) mais inteligente e distribuída.

*   **IA:** Injetar inteligência para otimização, automação e geração de conteúdo/insights.
*   **Supabase:** Backend de baixo custo e rápido para banco de dados (PostgreSQL), autenticação, e tempo real.
*   **Worker Local:** Execução de tarefas sensíveis ou pesadas na máquina do usuário/servidor local, permitindo processamento distribuído e offline.
*   **Cockpit Multi-aparelhos:** Interface central para gerenciar tarefas, monitorar workers e interagir com a IA, acessível via web, mobile, desktop (preferencialmente web-first e responsivo).

---

### **PLANO DE EVOLUÇÃO (3 Fases Curto Prazo)**

Prioridade em simplicidade, baixo custo e execução rápida.

#### **FASE 1: Fundação & Cockpit Básico (1-2 semanas)**

1.  **Configuração Supabase:**
    *   Criar projeto Supabase.
    *   Configurar autenticação (e-mail/senha, OAuth básico).
    *   Definir esquema de banco de dados inicial: `tasks` (id, title, description, status, assigned_to, created_at), `workers` (id, name, status, last_heartbeat).
2.  **Cockpit Web Responsivo (MVP):**
    *   Desenvolver interface web (React, Vue, Svelte ou similar, com framework CSS como Tailwind CSS ou Bootstrap).
    *   CRUD básico para tarefas (criar, ler, atualizar, deletar).
    *   Visualização de workers conectados e seus status.
    *   Integração com Supabase Auth e DB.

#### **FASE 2: Worker Local & Sincronização (2-3 semanas)**

1.  **Desenvolvimento Worker Local (MVP):**
    *   Criar um script ou pequena aplicação (Node.js ou Python) que possa rodar localmente.
    *   Funcionalidade: Conectar ao Supabase, "escutar" por novas tarefas atribuídas, executar uma ação de "exemplo" (e.g., logar no console, criar um arquivo local), atualizar o status da tarefa no Supabase.
    *   Mecanismo: Usar Supabase Realtime para notificação de tarefas e para o worker enviar `heartbeats` e updates de status.
2.  **Integração Worker no Cockpit:**
    *   Adicionar funcionalidade de "atribuir tarefa a worker" no cockpit.
    *   Exibir logs e progresso de tarefas executadas pelos workers no cockpit (via dados do Supabase).

#### **FASE 3: Injeção de Inteligência IA (2-3 semanas)**

1.  **Seleção & Integração de API de IA:**
    *   Escolher uma API de IA (Ex: OpenAI GPT-3.5/GPT-4, Google Gemini API).
    *   Configurar credenciais e integração via Supabase Edge Functions (se a lógica for simples e isolada) ou uma API intermediária simples.
2.  **Casos de Uso de IA (MVP):**
    *   **Geração de Descrição de Tarefa:** Com base em um título curto, a IA gera uma descrição mais detalhada para a tarefa.
    *   **Sugestão de Subtarefas:** A IA sugere subtarefas com base na descrição principal de uma tarefa.
    *   **Priorização Simples:** IA analisa palavras-chave para sugerir um nível de prioridade (ex: "urgente", "crítico").
3.  **Integração IA no Cockpit:**
    *   Adicionar botões/campos no formulário de criação/edição de tarefas para acionar as funcionalidades de IA (ex: "Gerar Descrição com IA", "Sugerir Subtarefas").
