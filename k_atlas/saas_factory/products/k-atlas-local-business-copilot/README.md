# K-Atlas Local Business Copilot

MVP gerado pelo K-Atlas SaaS Builder Agent.

## Problema
falta de cockpit simples para leads, tarefas, campanhas e relatorios

## Solucao
SaaS MVP em Streamlit com dashboard, CRM leve, campanhas, relatorios e admin

## Publico
negocios locais, prestadores de servico e operadores comerciais

## Monetizacao
setup inicial + assinatura mensal

## Governanca
- Sem API externa por padrao.
- Sem token em texto puro.
- Revisao humana obrigatoria antes de deploy.
