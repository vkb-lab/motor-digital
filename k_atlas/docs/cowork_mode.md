# Cowork Mode - K-Atlas Local

O objetivo do Cowork Mode é transformar o painel atual de abridor de links em um braço de trabalho real.

## Nova lógica

Pedido do usuário
→ interpretação de intenção
→ plano
→ ação segura
→ resultado
→ bloqueio honesto quando precisar de API
→ próximo passo

## Regras

1. Não fingir que leu dados quando apenas abriu site.
2. Não mostrar stacktrace gigante na tela.
3. Logs técnicos ficam em k_atlas/logs/debug.log.
4. A lousa mostra pensamento operacional limpo.
5. ENTER deve enviar comando.
6. Botões devem ser secundários.
7. Autoevolução não pode sobrescrever arquivos direto.
