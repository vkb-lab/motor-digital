# K-Atlas — Autonomia Assistida

O K-Atlas não deve ser um painel de botões.

Ele deve ser um agente de IA operacional capaz de trabalhar no digital com autonomia controlada.

## Fluxo

Pedido do usuário
→ interpretação
→ plano
→ confirmação quando necessário
→ execução
→ relatório
→ próximo passo

## Níveis de risco

### Nível 0
Pensar, planejar, gerar relatório.

### Nível 1
Abrir navegador, criar pasta, criar plano, listar arquivos.

### Nível 2
Criar ou alterar arquivos, instalar dependências, executar automações.

### Nível 3
Enviar email, publicar em redes sociais, apagar arquivos, mover arquivos, alterar configurações sensíveis.

## Regra principal

O K-Atlas pode agir, mas ações sensíveis precisam de confirmação explícita.

## Meta

Transformar o computador em um braço operacional de criação, desenvolvimento, automação e gestão digital.
