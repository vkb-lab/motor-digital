# Plano do K-Atlas

**Pedido original:** crie uma landing page para Parada Atlântida vender chopp grátis
**Intenção:** build_landing_page
**Resumo:** Criar estrutura inicial de uma landing page com arquivos, briefing e próximos passos.

## Etapas
### 1. Criar pasta do projeto
- Descrição: Criar uma pasta organizada dentro do workspace do K-Atlas.
- Ação: `create_project_folder`
- Risco: 1
- Exige confirmação: NÃO

### 2. Gerar briefing técnico
- Descrição: Criar README com objetivo, público, estrutura e páginas.
- Ação: `create_project_readme`
- Risco: 1
- Exige confirmação: NÃO

### 3. Gerar arquivos base
- Descrição: Criar arquivos HTML/CSS/JS iniciais ou plano Next.js conforme decisão.
- Ação: `create_basic_web_files`
- Risco: 2
- Exige confirmação: SIM

### 4. Salvar plano de execução
- Descrição: Registrar o plano em k_atlas/plans.
- Ação: `save_plan`
- Risco: 0
- Exige confirmação: NÃO
