# K-Atlas Context

Projeto:
K-Atlas OS

Objetivo:
Sistema operacional modular de agentes IA locais.

Stack:
- Python
- Streamlit
- GitHub
- JSON
- subprocess
- automações locais

Estrutura:
- agents/
- memory/
- campaigns/
- reports/
- live/
- content_packs/

Funções:
- campanhas automáticas
- memória persistente
- cockpit operacional
- orquestração IA
- aprovação de campanhas
- execução modular

Fluxo:
comando -> agentes -> campanhas -> cockpit -> GitHub -> memória

Regras:
- foco em execução
- comandos completos
- compatibilidade Windows
- UTF-8
- PowerShell
- simplificação operacional

Usuário:
- possui TDAH
- prefere respostas diretas
- não gosta de fragmentação
- precisa de baixa carga cognitiva

Objetivo futuro:
Transformar o K-Atlas em um sistema operacional completo de IA com múltiplos agentes coordenados, automações comerciais, geração de campanhas, memória evolutiva e cockpit central de operação.
