# KOS BRAIN PROVIDER PRIORITY PLAN

Data: 20260625_091237

## Decisão

O K-OS deve consultar primeiro sua inteligência interna evolutiva, depois IA local gratuita, depois quota gratuita cloud e só então provedores pagos/sensíveis com aprovação.

## Ordem oficial

1. K-OS Internal Evolutionary Intelligence
2. Ollama Local
3. LM Studio Local
4. LocalAI/vLLM/OpenAI-compatible local
5. Gemini Free Guarded
6. External Paid Providers Locked

## Regra

Não gastar token externo se o Baú, registries, políticas, auditorias e executores locais resolvem.

## Motivo

- reduz custo;
- aumenta privacidade;
- evita dependência de API paga;
- mantém autonomia local;
- preserva Google/Gemini free tier para tarefas onde realmente agrega;
- protege o sistema contra chamadas externas acidentais.
